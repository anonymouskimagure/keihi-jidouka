プライバシーポリシー

「経費自動化」は、運営者本人だけが使うツールです。

  • 使う権限は Google スプレッドシートの読み書き（https://www.googleapis.com/auth/spreadsheets）だけです。
  • 本人が所有する経費のスプレッドシートを読み書きするためだけに使います。
  • 取得したデータを第三者に提供・販売・広告に利用することはありません。
  • 認証情報は本人の端末内にだけ保存します。Google アカウントの「サードパーティ アクセス」からいつでも取り消せます。

Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
